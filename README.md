# rgtools

A collection of browser-based tools by Redgreens Studio, built with Astro and Preact.

## Requirements

- [Node.js](https://nodejs.org/) 20 or later
- npm (included with Node.js)

## Install

From the project directory, install the Node.js dependencies:

```sh
npm install
```

## Run locally

Start the Astro development server:

```sh
npm run dev
```

Open the local URL printed in the terminal (normally `http://localhost:4321`). The server reloads the page when source files change.

## Build for production

Create an optimized production build:

```sh
npm run build
```

The generated static site is written to `dist/`.

## Preview the production build

Build first, then serve the generated files locally:

```sh
npm run build
npm run preview
```

## Useful commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server. |
| `npm run start` | Alias for the development server. |
| `npm run build` | Generate the production site in `dist/`. |
| `npm run preview` | Preview the production build locally. |
| `npm run astro` | Run the Astro CLI directly. |
